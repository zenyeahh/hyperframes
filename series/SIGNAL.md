# «СИГНАЛ» — мини-сериал (3 серии × ~90 с, вертикаль 1080×1920)

Плоский векторный хоррор о выживании. Однажды в 6:00 на всех экранах мира
одновременно появляется надпись «НЕ ВЫХОДИТЕ НА УЛИЦУ». Те, кто выходит,
исчезают. Героиня — школьница Аня, одна в квартире.

## Серия 1 — «Не выходите на улицу» (готова: `signal-ep1/`)

| Время | Сцена                                                                                                        |
| ----- | ------------------------------------------------------------------------------------------------------------ |
| 0–9   | Хук: телефон в темноте, вспыхивает оповещение. Титр «СИГНАЛ · Серия 1».                                      |
| 9–22  | Спальня, 6:00. Аня с телефоном, на телевизоре то же оповещение.                                              |
| 22–33 | Монтаж экранов: билборд, банкомат, машина, часы — одно и то же.                                              |
| 33–46 | Вид из окна: пустой двор, качели качаются сами, птицы летят беззвучно; в окнах соседних домов стоят силуэты. |
| 46–60 | Закат 19:42. Дядя Коля выходит из подъезда («это чья-то шутка»). Рука Ани на стекле.                         |
| 60–70 | Тень дяди Коли на стене вытягивается и ломается. Резкая темнота: «Больше его никто не видел».                |
| 70–84 | Утро. На экранах «ОСТАЛОСЬ 4 812 331» — число падает прямо на глазах.                                        |
| 84–90 | Финальная карточка, «Серия 2 · скоро».                                                                       |

## Серия 2 — «Счётчик» (готова: `signal-ep2/`)

| Время   | Сцена                                                                                                                                                                                                                                  |
| ------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 0–7     | Аня процарапывает четвёртую черту на стене. «ДЕНЬ 4», «ОСТАЛОСЬ 3 906 118». Титр серии.                                                                                                                                                |
| 7–18    | Ревизия еды: продукты на столе по одному, счётчик калорий — итого 4 100 ккал.                                                                                                                                                          |
| 18–26.5 | Вода — 1,5 л из пятилитровки. В холодильнике кетчуп и половинка лимона.                                                                                                                                                                |
| 26.5–32 | Расчёт: 4 100 ÷ 2 000 ккал, 1,5 ÷ 0,75 л. Штамп «ХВАТИТ НА 2 ДНЯ», день 6 обведён: «дальше — ничего».                                                                                                                                  |
| 32–48   | Аня смотрит через камеру телефона: зум 1× → 5,6× на окно напротив, мальчик показывает листы («ТЫ ОДНА?», «ЕДА?», «МАГАЗИН. ДНЁМ МОЖНО»), Аня отвечает листом («ДА», «НА 2 ДНЯ»). Зум назад: сосед днём бегает к машине и возвращается. |
| 48–56   | Мамино сообщение с задержкой в три дня: «Я еду домой. Не открывай никому. Даже мне».                                                                                                                                                   |
| 56–75   | Подъезд в разрезе: Аня спускается 7→1, магазин — запасы растут до 5 дней. На часах 14:20, но за дверью закат. Бег наверх 1→7, крыша исчезает — появляется 8-й этаж. «В её доме семь этажей».                                           |
| 75–79   | Ночь: окно мальчика открыто настежь, фонарика нет.                                                                                                                                                                                     |
| 79–86.5 | Дверь. В щели под дверью — тени ног. Три стука. «Аня, открой. Это я».                                                                                                                                                                  |
| 86.5–90 | Финальная карточка, «Серия 3 · Открой».                                                                                                                                                                                                |

## Серия 3 — «Открой» (готова: `signal-ep3/`)

| Время   | Сцена                                                                                                                                                                  |
| ------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

| 22–44   | Дверь изнутри: ручка поворачивается, цепочка держит. «Я принесла еды» — в щель вкатываются те же продукты из ревизии. Шаги уходят наверх, табличка 7 → 8, свет гаснет. |

| 49.6–56 | Камера: мальчик вернулся, лист «НЕ ВЫХОДИ». Он машет — тень машет позже.                                                                                               |
| 56–63.5 | Счётчик падает до «1». «МОЖНО ВЫХОДИТЬ. ВАС ЖДУТ».                                                                                                                     |
| 63.5–70 | Во дворе стоят все пропавшие и смотрят на её окно; головы наклоняются разом.                                                                                           |
| 70–84   | Телефон гаснет; в чёрном экране за Аней — вытянутая фигура. Три стука — изнутри квартиры.                                                                              |
| 84–90   | Финальная карточка: «СИГНАЛ · Открой · КОНЕЦ?».                                                                                                                        |
